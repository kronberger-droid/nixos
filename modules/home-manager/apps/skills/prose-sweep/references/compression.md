# Compression

Adapted from `author_profile/compression_patterns.md` in
SNL-UCSB/paper-writing-skill (MIT, Copyright (c) 2026 Arpit Gupta; see
`LICENSE-paper-writing-skill`). Kept patterns 1 to 4 and 7, reworded for a
thesis; dropped claim-first headings and the takeaway and ratio material.

Use only when the user asks to cut length. Compression is a structure-level
edit: it moves and deletes content, so it runs as `scientific-writing`'s
structure pass, never folded into a line pass. Every cut appears individually in
the change list, because each is a decision the author may reverse.

1. **Shorten sentences.** Remove subordinate clauses and qualifiers that carry no
   information. Stop at the claim-fidelity floor: a qualification the author put
   there on purpose stays.
2. **Merge paragraphs** that make one point with different examples into one
   paragraph with the strongest example.
3. **Replace generic adjectives** with the number or mechanism behind them, or
   delete them. See `mechanical.md`, adjectives.
4. **Cut tutorial material** the reader already knows. A thesis has a broader
   audience than a conference paper (examiners outside the subfield), so the
   background chapter legitimately teaches. Apply this to repetition of
   textbook material outside the background chapter, and to background beyond
   what later chapters use.
5. **Move numbers into tables.** A run of sentences listing values per condition
   becomes a table plus prose that interprets the pattern. Every value moves
   verbatim.
